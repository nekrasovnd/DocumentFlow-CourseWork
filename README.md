# DocumentFlow — Система документооборота с электронной подписью

Веб-приложение для управления документами с поддержкой электронной подписи (RSA-PSS, SHA-256).

## Возможности

- Регистрация и аутентификация пользователей
- Автоматическая генерация ключевой пары RSA-2048 и сертификата X.509 при регистрации
- Загрузка и хранение документов (PDF, DOCX, XLSX, TXT, PNG)
- Подписание документов электронной подписью (RSA-PSS, SHA-256)
- Верификация электронной подписи с проверкой целостности файла
- Просмотр открытого ключа и сертификата пользователя

## Технологии

- **Python 3.10+**
- **Flask** — веб-фреймворк
- **cryptography** — криптографические операции (RSA, X.509, SHA-256)
- **SQLite** — база данных
- **Jinja2 и локальные CSS-стили** — пользовательский интерфейс

## Установка и запуск

1. Распаковать архив и перейти в каталог DocumentFlow.

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Запустить приложение:
```bash
python app.py
```

4. Открыть в браузере: http://127.0.0.1:5000

## Безопасность учебной реализации

- закрытые ключи хранятся в базе данных в формате PEM с шифрованием паролем пользователя;
- формы POST защищены CSRF-токеном;
- файлы сохраняются под случайными внутренними именами и ограничены размером 16 МиБ;
- доступ к документам ограничен владельцем;
- перед подписанием повторно проверяются пароль и контрольная сумма файла;
- сертификат X.509 является самоподписанным и не заменяет сертификат аккредитованного удостоверяющего центра.
