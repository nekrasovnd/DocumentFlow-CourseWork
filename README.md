# DocumentFlow

Курсовой проект — веб-приложение для хранения документов, создания и проверки электронной подписи. Используется схема RSA-PSS с хеш-функцией SHA-256.

## Возможности

- Регистрация и вход в учётную запись.
- Автоматическое создание ключевой пары RSA-2048 и самоподписанного сертификата X.509.
- Загрузка файлов с расширениями PDF, DOC, DOCX, XLSX, TXT, PNG и JPG.
- Просмотр и скачивание собственных документов.
- Подписание документов после подтверждения пароля.
- Проверка подписи и целостности файла.
- Просмотр открытого ключа и сертификата пользователя.

## Технологии

Python 3.10+, Flask, SQLite, cryptography, Werkzeug, Jinja2, HTML и локальные CSS-стили. Для клонирования репозитория требуется Git.

## Установка и запуск в Windows PowerShell

```powershell
git clone https://github.com/nekrasovnd/DocumentFlow-CourseWork.git
cd DocumentFlow-CourseWork
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-tested.txt
.\.venv\Scripts\python.exe app.py
```

Открыть в браузере: http://127.0.0.1:5000

Активация виртуального окружения не требуется. Если проект уже скачан, выполнить команды начиная с создания `.venv` в папке с `app.py`. Для остановки сервера нажать `Ctrl+C`.

## Установка и запуск в Linux и macOS

```bash
git clone https://github.com/nekrasovnd/DocumentFlow-CourseWork.git
cd DocumentFlow-CourseWork
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-tested.txt
.venv/bin/python app.py
```

`requirements-tested.txt` фиксирует проверенные версии основных зависимостей. В `requirements.txt` указаны их минимальные версии.

## Порядок работы

1. Зарегистрировать пользователя с паролем длиной от 8 до 128 символов. Ключи и сертификат создаются автоматически.
2. Загрузить документ через веб-интерфейс.
3. Подписать документ, подтвердив пароль учётной записи.
4. Открыть результат проверки подписи.
5. При необходимости скачать документ или просмотреть открытый ключ и сертификат.

## Проверка

В Windows PowerShell из корня проекта:

```powershell
.\.venv\Scripts\python.exe test_all.py
.\.venv\Scripts\python.exe test_web.py
```

В Linux и macOS:

```bash
.venv/bin/python test_all.py
.venv/bin/python test_web.py
```

Тесты используют временные каталоги и отдельные базы данных. Проверяются создание и верификация подписи, обнаружение изменения документа, операции с базой, регистрация, загрузка, подписание и ограничения доступа. Веб-проверки выполняются без запуска браузера.

## Особенности учебной реализации

- Пароли хранятся в виде хешей; закрытые ключи — в зашифрованном PEM-формате с использованием пароля пользователя.
- POST-запросы защищены CSRF-токеном.
- Доступ к документам ограничен владельцем.
- Файлы сохраняются под случайными внутренними именами; проверяется разрешённое расширение. Максимальный размер HTTP-запроса — 16 МиБ.
- Перед подписанием повторно проверяются пароль и контрольная сумма файла.
- Сертификаты X.509 являются самоподписанными. Проект не реализует квалифицированную электронную подпись.
- Приложение запускается локально на `127.0.0.1:5000` с отключённым режимом отладки.
